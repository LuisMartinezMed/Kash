# Frontend de Kash

Este directorio contiene la aplicación Expo SDK 54 de Kash, construida con React Native, TypeScript y Expo Router.

La descripción del producto, la instalación completa, la arquitectura y las reglas de contribución se encuentran en el [README principal](../README.md).

## Comandos principales

Ejecutados desde la raíz del repositorio:

```powershell
corepack yarn install --cwd frontend --frozen-lockfile
corepack yarn --cwd frontend start
corepack yarn --cwd frontend lint
corepack yarn --cwd frontend typecheck
corepack yarn --cwd frontend test
```

Para otros comandos y requisitos de plataforma, consulta la [guía de desarrollo](../docs/development.md).
